# Seed Dataset V0

Base temporária utilizada para desenvolvimento inicial do projeto
"Promessa ou Contradição?".

## Escopo

Planos de governo de candidatos à Presidência da República nas
Eleições Brasileiras de 2026.

## Objetivo

Permitir o desenvolvimento paralelo das primeiras versões de:

- parsing de PDFs;
- extração de texto;
- chunking;
- modelagem de dados;
- structured extraction;
- retrieval/RAG;
- anotação e avaliação.

## Importante

Este dataset é uma base de desenvolvimento.

Ele NÃO representa o corpus experimental final da pesquisa.

Os arquivos em `raw/` devem ser tratados como dados brutos e não
devem ser alterados durante o processamento.
